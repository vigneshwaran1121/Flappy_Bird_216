# Flappy_Bird_216
First Unity Project ( Flappy Bird Clone - Unity )

A simple Flappy Bird-style 2D game built using Unity.

This project was created to practice:
- Unity 2D physics
- Prefabs & object spawning
- UI with TextMeshPro
- Game loop management
- Score & high score system

---

Gameplay

- Tap / Click to make the bird fly upward
- Avoid the pipes
- Collect coins for extra points
- Game ends when the bird hits a pipe or ground
- High score is saved locally

---

Built With

- Unity (6000.3.8f1)
- C#
- TextMeshPro
- Unity 2D Physics
- Android Build Support

---

Features

- Smooth bird physics with gravity
- Pipe spawning system with random height
- Coin spawning every 4 pipes
- Score tracking
- High score saved using PlayerPrefs
- Game Over UI panel
- Restart functionality
- Android-ready build setup

---

Project Structure

Scripts Included:
- `FlyBehavior.cs` → Handles bird movement
- `PipeSpawner.cs` → Spawns pipes at intervals
- `MovePipe.cs` → Moves pipes left
- `CoinPickup.cs` → Handles coin collection
- `ScoreManager.cs` → Manages score & high score
- `GameManager.cs` → Controls game over & restart

---

How to Run

1. Clone this repository
2. Open project in Unity
3. Open the main scene
4. Press Play

To build for Android:
- Switch platform to Android
- Build APK
